v0.12 generated-code benchmark
==============================

Benchmark
---------
Deterministic adaptation of Algebra sm_dmp0 ALDORTEST.
RandomNumberGenerator is seeded with 1 before makeZoo.
Both variants produced output SHA-256:
e39d0470a682e8b05192d5e7cccb8178ee6142bb867ec11c72cb1831e87628aa

Comparison design
-----------------
Baseline compiler: v0.01
Current compiler:  v0.12 (compiler sources unchanged from sealed v0.11)
Support root:      held fixed for both variants
Aldor options:     -O -Qall
Generated C:       compiled by GCC with effective -O3
Warmups:           2 per executable
Measured pairs:    7
CPU affinity:      CPU 0
Primary metric:    median of paired current/baseline process-CPU ratios

Results
-------
CPU baseline median: 2.258179 s
CPU current median:  2.435839 s
CPU median paired current/baseline ratio: 1.013550
CPU paired change: +1.355%
CPU mean paired ratio: 1.006131

Wall baseline median: 2.259086 s
Wall current median:  2.441438 s
Wall median paired current/baseline ratio: 1.013234
Wall paired change: +1.323%

Interpretation
--------------
No material generated-code performance loss is demonstrated by this benchmark.
The paired CPU-time result is about +1.4% and the run-to-run host
variation is several percent.  Future releases should retain the raw paired TSV
and compare the paired ratio against the v0.01 baseline.
