v0.15 generated-code benchmark
==============================

Benchmark
---------
Deterministic adaptation of Algebra sm_dmp0 ALDORTEST.
RandomNumberGenerator is seeded with 1 before makeZoo.
Both variants produced output SHA-256:
e39d0470a682e8b05192d5e7cccb8178ee6142bb867ec11c72cb1831e87628aa

Comparison design
-----------------
Baseline compiler: v0.01 (commit 772b6a7, rebuilt on this host)
Current compiler:  v0.15 release candidate
Support root:      held fixed for both variants
Aldor options:     -O -Qall
Generated C:       compiled by GCC with effective -O3
Compile pairs:     5, alternating order
Execution warmups: 2 per executable
Execution pairs:   7, alternating order
CPU affinity:      CPU 0
Primary execution metric: median paired current/baseline CPU-time ratio

primary paired CPU metric.  Compiler+backend compilation is about 6% faster on
this run.  There is no generated-code performance regression.
